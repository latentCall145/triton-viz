# On startup
- directs to "Edit" tab

# When clicking "Run"
- redirects to "Graph" tab
- When user clicks on line, it highlights and visualizes the specific op(s) called
  - load visualized here, each op requires its own visualization code
- any enclosing for/while loops have sliders which allows users to adjust to see op at different times
- program IDs also have adjustable sliders
- tensor shapes shown (replace K, N with int lexemes)
- handlebar to adjust code/op vizr pane size
